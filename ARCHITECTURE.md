# RE:Control — Архитектурная документация (Внутренняя)
Этот документ отслеживает реализованные механики для последующего формирования финального README.md.

## 1. Базовые системы
- **Electron + React + Vite:** Каркас приложения. Взаимодействие идет через защищенный `preload/index.ts`.
- **REFramework Bridge:** Общение с игрой происходит через запись в файл `recontrol_in.txt` (путь к игре настраивается). Lua-скрипт внутри RE2 читает этот файл каждый фрейм.

## 2. Setup Wizard (Мастер Установки)
- Поддерживает 13 игр (RE2-RE8, DMC5, DD2, MH, SF6) и различные ветки модов (TDB).
- **Трехуровневый поиск:** Чтение реестра Steam (`libraryfolders.vdf`) -> Сканирование дисков -> Ручной выбор `.exe`.
- **Процесс:** Автоматически извлекает `dinput8.dll` и скрипты `autorun/` прямо в игру из встроенных zip-архивов.

## 3. Интеграция Twitch (TwitchBridge.ts)
- Использует `tmi.js` для анонимного подключения. Не требует OAuth.
- Парсит мета-теги (`tags.badges`) для определения статуса зрителя (VIP, Subscriber, Moderator, Broadcaster).
- Автоматически отключает внутренних ботов (`ChatSimulator`), если подключен реальный канал.

## 4. Режимы Управления (VotingManager.ts)

### 4.1 Crowd Control (Автопилот)
- Бесконечный цикл: Голосование (60с) -> Эффект -> Кулдаун -> Новое голосование.
- **Pacing (Кулдауны):** Speedrun (2 мин), Standard (5 мин), Marathon (10 мин).
- **Карма (SQLite):** За каждое успешное голосование зритель получает +1 карму в БД `re_control_data.sqlite`.

### 4.2 Traitor Mode (Механика "Предатель")
- **Защита:** В пул предателей попадают только доверенные зрители (`isTrusted == true`), проявившие активность за последние 15 минут.
- **Процесс:** Стример нажимает `Invoke Traitor`. Автопилот ставится на паузу. Случайный доверенный зритель получает временную власть.
- **Казнь:** Предателю выдается 5 уникальных/жестких опций. При вводе цифры эффект срабатывает мгновенно, и режим возвращается в Автопилот.

## 5. Интеграция Уведомлений (Bot Chatting)
- Для отправки сообщений в чат требуется авторизация (OAuth Token).
- Пользователь вводит Bot Username и OAuth Token в настройках UI.
- Данные сохраняются локально. TwitchBridge при наличии токена подключается с полем identity и получает права на запись (client.say).
- Уведомления автоматизированы для: старта голосования, победы эффекта, запуска режима Предателя.
